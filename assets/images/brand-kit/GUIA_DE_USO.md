# Logotipo Klarock — Guía de uso

Sistema de logo de Klarock. Símbolo: una **K** con asta sólida y brazos
formados por **módulos ascendentes** — comunica tecnología (datos modulares) y
crecimiento (el ascenso), sobre la confianza que dan el azul marino y la
tipografía Montserrat.

## Archivos incluidos

Cada versión viene en **SVG** (vectorial, escala infinita, para imprenta y web)
y **PNG** (alta resolución 4x, fondo según versión).

| Archivo | Uso recomendado |
|---|---|
| `klarock_horizontal_marino` | **Logo principal.** Webs, presentaciones, fondos oscuros. |
| `klarock_horizontal_blanco` | Documentos, papelería, fondos claros. |
| `klarock_horizontal_transparente` | Sobre fotos o fondos claros (sin caja). |
| `klarock_monograma_dorado` | Foto de perfil, app icon, sello. |
| `klarock_monograma_marino` | Ícono sobre fondos claros. |
| `klarock_simbolo_transparente` | Favicon, marca de agua, watermark de reportes. |

## Colores de marca

| Color | HEX | Uso |
|---|---|---|
| Azul marino | `#1B3A6B` | Principal |
| Marino profundo | `#0f2647` | Fondos oscuros |
| Dorado | `#C9A84C` | Acento principal |
| Dorado claro | `#e3cd86` | Detalle (cima del ascenso) |

## Tipografía
**Montserrat ExtraBold** para el nombre. (En los archivos el texto ya está
vectorizado, así que no necesitas la fuente instalada para usarlos.)

## Reglas básicas
- Deja un margen libre alrededor del logo de al menos la mitad del alto del
  símbolo.
- No deformes, rotes ni cambies los colores del logo.
- Para tamaños muy pequeños (favicon), usa el monograma/símbolo, no el horizontal.
- Usa siempre el SVG cuando sea posible; el PNG solo donde no se acepte vectorial.

> Nota: este es un logo original creado para Klarock. Para registrarlo como
> marca, conviene una verificación de disponibilidad con un especialista en
> propiedad industrial (IMPI en México).
